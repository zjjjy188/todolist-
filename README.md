# todolist-

一个桌面 todolist 小插件，简洁为主。

平时半透明、不抢注意力；鼠标移上去会变实。窗口始终浮在最前，不占任务栏。任务按五个分组显示：**ddl / 待做 / 学习 / 影视 / 娱乐**。

目前只支持 Windows。

## 运行

需要安装 [Node.js](https://nodejs.org/)。

```bash
git clone https://github.com/zjjjy188/todolist-.git
cd todolist-
npm install
npm start
```

也可以在 `npm install` 之后，双击文件夹里的 `启动待办.vbs`。

第一次打开如果弹出 Windows 安全提示，选「仍要运行」。

开机后会自动启动。

## 使用方法

### 切换 To do / Done

顶部是一体的滑动开关：

- 点 **To do** 或 **Done**
- 也可以按住滑块左右拖

数字是当前未完成 / 已完成的条数。切换时列表会淡入淡出，窗口大小保持不变。

### 完成和恢复

- 在 To do 里点一条任务，它会进 Done
- 在 Done 里再点一次，会回到 To do

### 添加任务

把鼠标移到分组标题右侧，点 **+**。也可以在 To do 里右击分组标题。

输入文字后按 Enter 保存，Esc 取消。

### 改名字、换顺序

- 右击任务，或双击任务文字，可以改名字
- 按住一条任务直接拖，只能在同一个分组里换顺序

### 窗口

- 空白处按住可以拖动窗口
- 拖到屏幕边缘外超过一半，会收成侧边小圆球；再拖回来会展开
- 右上角 **–** 也会收到侧边；圆球上的数字是未完成数量，点一下展开
- 右上角 **×** 关闭程序
- 拖窗口边角可以改大小；改过之后，这次运行里不会再自动缩放。下次启动仍会按任务数量自适应一次

### 清空已完成

切到 Done，点右下角 **清除全部**。再点一次确认后才会删掉。

## 说明

- 任务保存在本地的 `data.json`，不会上传到 GitHub。
- 窗口位置记在 `%APPDATA%\jiujiu-todo\bounds.json`。
- 克隆下来第一次打开时，如果没有 `data.json`，会显示一组示例任务，之后改过的内容只留在你这台电脑上。
- 这个仓库只放这个桌面待办项目。
