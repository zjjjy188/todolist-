# todolist-

一个桌面 todolist 小插件，简洁为主。

Windows 桌面挂件：半透明、分组任务（ddl / 待做 / 学习 / 影视 / 娱乐）、To do / Done 切换、拖拽排序、拖到屏幕边缘收成小球。

## 运行

需要 Windows，并安装 [Node.js](https://nodejs.org/)。

```bash
git clone https://github.com/zjjjy188/todolist-.git
cd todolist-
npm install
npm start
```

也可以在 `npm install` 之后，双击文件夹里的 `启动待办.vbs`。

第一次打开如果弹出安全提示，选「仍要运行」。

## 说明

- 任务保存在本地的 `data.json`，不会上传到这个仓库。
- 这个仓库只放这个桌面待办项目。
